# Strandskydd
## Grupp 1 - emot
- Jobbigare att bygga
	- Bygga någon annanstans, skydda biologisk mångfald
- Ökar risken för nedskräpning med fri tillgång
	- Finns lagar mot nedskräpning
- Gamla hus utan tillstånd kan tvingas rivas
	- 
## Grupp 2 - för
- Viktigare att förstöra biologisk mångfald för att få bygga på en specifik plats?
	- Ja
- Byggen kan orsaka föroreringar
- Kan förhindra konsekvenser av klimatförändringar, att behålla stränder kan skydda mot översvämningar. Rötter från träd skyddar stränder från erosion
	- Svårt att bygga bryggor
	- Markägaren har ett ansvar att skydda vid byggen
- Skyddar biologisk mångfald nära stränder
# Vindkraft
## Grupp 3 - för
- Förnybar och billig utsläppsfri energikälla som aldrig tar slut
	- Instabil, låg produktion när det är vindstilla
- Bra sätt att öka den totala produktionen
- Bra förhållanden för vindkraft längs svenska kusten
	- Förstör utsikt

## Grupp 4 - emot
- Skog behöver skövlas för att anlägga vindkraftverk
	- Går att bygga i öppna områden
- Bör inte byggas nära bebyggelse
	- Estetiska värden viktigare än energiproduktion?
	- 
- Behöver andra energikällor för att stabilisera produktionen över tid, bygg mer av annat
	- Kärnkraftverk kan få härdsmälta, osäker energikälla
- Vindkraftverk i havet kan störa det lokala fisklivet
- Opålitlig energikälla
# Sänkt bensinskatt
## Grupp 5 - för
- Fler kan ha råd att köra bil, ökar tillgänglighet
	- Leder till större utsläpp som ökar växthuseffekten
- Kollektivtrafiken kommer inte minska pga detta
- Fler och fler kör elbil, kan minska miljöpåverkan
	- Bensinbilar försvinner inte pga att elbilar ökar
	- Batteriproduktion leder till stora utsläpp
## Grupp 6 - emot
- Lägre bensinskatt leder till att fler kör bil
	- Sker inte på en gång
- Viktigt att tänka långsiktigt
- Sänkt bensinskatt innebär mindre statliga intäkter
	- Andra länder säljer olja, kostar pengar
- Fler bilar innebär mer slitage på infrastrukturen och större risk för olyckor
	- Mer infrastrukturarbete innebär fler jobb
- Sverige har klimatmål, som är viktiga att nå, kan leda till viten
